# 快捷方式恢复助手（Shortcut Restorer）

面向 Windows 7 / 8 / 10 / 11 的绿色小工具。

重装系统后，桌面和开始菜单里的快捷方式常常会丢失，但软件本体（.exe 文件）仍然完整保留在磁盘上。本工具通过**快速扫描磁盘中的应用主程序**，帮你**批量重建桌面或开始菜单快捷方式**，不用重新安装软件。

---

## 一、功能特点

- **已安装应用模式（与应用图标缩略显示）**
  - 与「设置 > 应用 > 已安装的应用」一致的独立应用口径：读取注册表 Uninstall 键（64 位 / 32 位 / 当前用户三个视图），与应用装在哪个盘无关，自动汇总 C 盘、D 盘、E 盘等各盘安装的软件；
  - 每个条目都是独立应用的主启动程序（自动排除卸载器、安装器、更新器、驱动工具与 MSI 缓存），不是软件内部的附属功能；
  - 左侧以 16×16 缩略图显示每个应用的真实应用图标（取自主程序或注册表记录），识别不到时用通用图标兜底；
  - 显示应用名称、主程序路径、发行公司、版本与安装大小，支持搜索过滤、全选/反选、批量添加桌面/开始菜单快捷方式、导出 CSV。
- **三种扫描范围**
  - 快速扫描：只扫描常见程序安装目录（Program Files、Program Files (x86)、当前用户的 Programs 目录），一般几秒到几十秒即可完成；
  - 全盘扫描：可勾选一个或多个磁盘分区完整扫描，多线程并行加速；
  - 指定目录：只扫描你选择的某个文件夹。
- **只显示真正能打开应用的图形界面主程序（核心能力）**
  - 自动识别 exe 是否带图形界面（解析 PE 子系统），命令行 / 控制台程序（如 cmd、Python 等）不再出现在结果中；
  - 同一个软件只保留一个主启动程序（按产品名去重），例如扫描出百度网盘时会只显示「百度网盘 / BaiduNetdisk.exe」一条，不再出现 BaiduNetdiskUpdate、BaiduNetdiskService 等更新器和后台服务；
  - 自动隐藏系统自带与附带组件：Edge、OneDrive、Teams、Windows Media Player、Windows 照片查看器、触摸键盘、Java SDK 工具，以及各软件自带的 update / uninstall / daemon / service / helper / plugin 等附属文件；
  - 可勾选「隐藏无产品名称的程序」进一步过滤杂项（默认勾选）。
- **智能过滤，避免噪音**
  - 自动跳过系统目录（Windows、Recycle Bin、System Volume Information、Recovery 等）与无关目录（node_modules、.git、ProgramData\Package Cache 等）；
  - 自动跳过安装程序类文件（setup.exe、install.exe、uninstall*.exe、msiexec、vcredist、dotnetfx 等），避免把安装包误认成应用。
- **结果识别清晰**：从 exe 文件版本信息中提取产品名、公司、版本号，列表支持关键字即时筛选、全选 / 反选；**搜索不区分英文大小写、不区分全角/半角，也不区分中文与英文**——输入全角「Ｃｈｒｏｍｅ」可匹配「Chrome」；中文名可用拼音或首字母搜索（如输入 `weixin`、`wx` 能匹配「微信」）；常见应用的中文名与英文名互通（如输入 `wechat` 能找到「微信」、输入「钉钉」能找到 `DingTalk`）；路径过长时自动省略，鼠标悬停可查看完整路径。
- **一键批量添加快捷方式**
  - 添加到桌面；
  - 添加到开始菜单（当前用户）；
  - 添加到开始菜单（所有用户，需要管理员权限）；
  - 同名自动去重（自动追加 (2)、(3)…），不会覆盖已有快捷方式。
- **界面简洁友好**
  - 统一使用微软雅黑字体（Win7 及以上系统自带），按钮加高、间距统一，文字不再被遮挡；
  - 鼠标悬停在「开始扫描」「添加到开始菜单」「所有用户开始菜单」「浏览…」「隐藏无产品名称的程序」等控件上有用途提示；
  - 按钮文案简化：开始菜单按钮直接写「添加到开始菜单」与「所有用户开始菜单」，用途一目了然。
- **其他**：支持“打开所在文件夹”、导出扫描结果为 CSV、随时停止扫描。

## 二、使用方法

1. 双击 **启动快捷方式恢复工具.bat**（推荐，自动带上必要的 PowerShell 启动参数）；
2. 顶部选择模式：
   - **已安装应用模式**：直接列出与系统设置一致的独立应用（带应用图标），点击 **加载应用** 即可；
   - **扫描程序模式**：在界面中选择扫描范围；「排除系统自带程序」「隐藏无产品名称的程序」默认已勾选，直接点击 **开始扫描** 即可；
3. 在结果列表中勾选需要恢复的应用，点击 **添加到桌面** 或 **添加到开始菜单**；
4. 如需添加到“所有用户”开始菜单，请右键 bat → **以管理员身份运行**。

也可以手动用命令启动（进入解压目录后）：

    powershell -NoProfile -ExecutionPolicy Bypass -STA -File ShortcutRestorer.ps1

### 命令行模式（可选）

    powershell -NoProfile -ExecutionPolicy Bypass -STA -File ShortcutRestorer.ps1 -HeadlessScan "C:\Program Files" -OutFile result.csv

- `-HeadlessScan <目录>`：扫描指定目录，不显示图形界面；
- `-InstalledApps [-OutFile 文件]`：直接输出“已安装应用模式”的应用列表（与系统设置口径一致，含主程序路径与图标源），不显示图形界面；
- `-OutFile <文件>`：把结果导出为 CSV（扫描模式输出“主程序 + 按产品去重”结果；应用模式输出注册表口径应用列表）；
- `-SelfTest`：运行内置自检（编译扫描引擎、GUI 过滤、应用模式口径断言、创建/读回测试快捷方式、搜索归一化与中英文/拼音匹配断言、表单构建等），输出 `ALL SELF TESTS PASSED` 即正常。

## 三、扫描策略说明（为什么快、为什么结果干净）

- 扫描用 C# 内嵌引擎执行（Add-Type 编译），对每个根目录启动独立后台线程并行遍历，结果通过队列批量送到界面，不阻塞 UI；
- 快速扫描默认只覆盖**应用实际安装的位置**，避免全盘漫游；全盘扫描时也可关闭系统目录排除项以完整遍历；
- 只读取 exe 文件，且通过文件版本信息轻量提取产品名/公司/版本，不做深度解析；
- **图形界面识别、内置组件排除、产品去重都在扫描过程中同步完成**，界面只刷新最终的主程序行，小白用户看到的列表就是可以直接双击打开的软件；
- 全盘扫描快慢取决于磁盘类型与文件数量（机械硬盘明显慢于 SSD），可随时点击“停止”。

## 四、兼容性说明

- 系统：Windows 7 / 8 / 8.1 / 10 / 11（32 位、64 位均可）；
- 依赖：系统自带的 PowerShell 2.0 及以上、.NET Framework 3.5 及以上（Win7 默认满足，Win10/11 默认满足）；
- 脚本按 PowerShell 2.0 语法编写并保存为 UTF-8 带 BOM，避免中文乱码；
- 全程无需安装、绿色便携，可放在 U 盘使用。

## 五、权限与执行策略说明

- 启动器 bat 使用 `-ExecutionPolicy Bypass`，**仅用于**绕过 PowerShell 脚本执行策略限制，**不会提升权限**，也不是病毒行为；
- 修改“当前用户的桌面/开始菜单”不需要管理员权限；
- 修改“所有用户的开始菜单”需要管理员权限，请右键 bat → 以管理员身份运行；未提权时会给出提示而不是失败退出；
- 若杀毒软件拦截，可右键查看脚本源码确认（脚本为纯本地 PowerShell + C#，不联网、不上传任何数据）。

## 六、注意事项

- 请把整个文件夹解压后再运行，不要直接在压缩包内双击（PowerShell 无法从压缩包直接执行脚本）；
- 首次启动可能因 PowerShell 策略设置较慢，属正常现象；
- 全盘扫描建议在勾选磁盘时先只选操作系统盘之外的数据盘，避免扫描 Windows 目录浪费时间（排除项默认已跳过 Windows 目录）；
- 如果某个软件没有出现在列表里，可以先取消勾选「隐藏无产品名称的程序」再扫描；本工具只显示主程序，更新器、后台服务等附属文件一律不列出；
- 已安装应用模式基于注册表 Uninstall 键，与系统设置显示的「已安装的应用」同源；个别绿色软件（免安装版）不在该列表内，可用「扫描程序模式」查找；
- 应用模式会自动跳过 .NET 运行时、Visual C++ 运行库、WebView2 等“非独立应用”的组件条目，只保留可创建快捷方式的应用；
- 工具只创建“快捷方式”，不会复制或移动任何程序文件，不会修改注册表，可放心使用；
- 搜索的中英文互通依赖内置的常见应用中英文对照表与拼音表（拼音覆盖 GB2312 常用汉字）；未收录的中英对照词可能无法互通，此时中文名仍可用拼音全拼或首字母搜索，英文名仍可用原词搜索。
